当前位置：空白记录单

##### 空白记录单

| 一件事，几项必要信息 | 填写 |
| --- | --- |
| 事件及日期／观察时间 |  |
| 已知事实：谁在何时做了什么？依据是亲历、自述还是尚有分歧？ |  |
| 对我／对共同事务有什么影响？ |  |
| 我目前怎样解释？还有什么未知？ |  |
| 下一步具体做什么？哪些已共同确认，哪些只是我的提议？ |  |
| 谁承担，是否有相应条件？ |  |
| 到什么时间，或出现什么新事实时回看？ |  |
| 回看结果：已完成／调整后继续／暂缓／结束；仍未解决什么？ |  |
| 记录状态：关闭，或因哪一项新事实重新打开？ |  |

只选影响当前决定的内容。敏感资料由当事人掌握，按需要最少共享；无需为填表交出私人原件、全部聊天或账户。若有危险或可能招致报复，先考虑记录与共享是否增加暴露，不把对方同意记录设为保护自己的前提。
