##### 已填例二：经历重要，身份期待不同

回看[第10.2节情境B](../../../book/人间爱情指南-全书整合稿-v1.2.md#unit-10-2)中赵禾与陆安澄清经历意义的时点。两人已确认恋爱与排他，没有婚约。赵禾以为亲密意味着两人已共同选择以婚姻为方向了解；陆安珍惜恋爱和经历，却仍不确定自己是否想进入婚姻。此处不同于已经想结婚、只待判断两人是否适婚。

| 字段 | 这次填写 |
| --- | --- |
| 感受与意义 | 赵禾既有快乐与留恋，也有失落；陆安确认亲密和恋爱有价值 |
| 共同确认过什么 | 恋人身份及排他；没有双方共同确认的婚姻方向，更没有婚约 |
| 仍需判断什么 | 赵禾能否接受陆安尚未确定自己是否想进入婚姻；不能由已有经历补成一致 |
| 当前行动 | 先听清各自意思，不通过更多身体亲密或直接订婚消除差异 |
| 后来的决定 | [第10.4节中赵禾选择结束恋爱](../../../book/人间爱情指南-全书整合稿-v1.2.md#unit-10-4)；不是此前经历无价值，也不须对方先批准 |

本页得到的是当前意愿和信息差异，不是亲密程度得分。诚实的差异需要选择，明确的施压需要处理行为，健康知情缺口转[附录K.2](../../../book/人间爱情指南-全书整合稿-v1.2.md#unit-K-2)。真实责任按[附录J.2](../../../book/人间爱情指南-全书整合稿-v1.2.md#unit-J-2)另行辨认；经历无法退回未发生，不意味着未来只能沿原方向继续。
