##### 轻量记录：空白版

先用一句话标识这件事，例如“那次晚餐分工讨论”，需要时补日期。后续沿同一件事记录新信息，避免把每次想起都当成另一场违约。只保留对理解、安排或必要保护有用的信息。

| 字段 | 本次记录 |
| --- | --- |
| 这件事：具体发生什么，当前知道与不知道什么 |  |
| 主类及理由；必要时增加次类 |  |
| 目前的安排：谁愿意做什么，条件和权限是否可用 |  |
| 已处理：哪些已实际完成，哪些只是约定 |  |
| 余波：仍有什么体验、负担或后果，是否属于原事件 |  |
| 重谈条件：新事实、未处理损害或方案失效时怎样回来 |  |
| 当前状态：仍在处理、暂缓并有条件、已关闭，或不再继续 |  |
