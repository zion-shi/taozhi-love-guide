##### 特殊重叠另记一栏

如果感情同时连接职业、企业或组织资源，补下面的记录，不把正常交往直接变成特权承诺。

| 当前角色与具体资源 | 谁确有决定权限，依据是什么 | 会影响谁的权益 | 可用的独立信息或处理渠道 |
| --- | --- | --- | --- |
|  |  |  |  |

例如[9.6的职业关系情境](../../../book/人间爱情指南-全书整合稿-v1.2.md#unit-9-6)中，乙可以赠送自己买的书，却没有被单位授权安排恋人甲的岗位；乙的父亲参与工作评价，也需按真实组织职责行事。不能把“愿帮你问问”填成组织已经承诺，也不能为证明爱情要求甲放弃正常职业选择。
