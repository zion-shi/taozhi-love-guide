当前位置：可用工具的范围

##### 可用工具的范围

| 工具组 | 当前能帮助什么 | 使用限制 |
| --- | --- | --- |
| [A](../../../book/人间爱情指南-全书整合稿-v1.2.md#unit-A-1) 阅读、系统与节点 | 按问题找到内容，区分形成程度、运行、选择及新增责任 | 六节点不是七风险阶段，身份不自动放行具体行动 |
| [B](../../../book/人间爱情指南-全书整合稿-v1.2.md#unit-B-1) 寻找与校准 | 整理生活想象、底线偏好、渠道和有限行动后的变化 | 不把人变成总分，不造条件交集的成功率 |
| [C](../../../book/人间爱情指南-全书整合稿-v1.2.md#unit-C-1) 互动与生成 | 准备邀约，观察双向参与、普通相处价值与日常经营 | 频率和投入不能代替积极体验，记录不能制造喜欢 |
| [D](../../../book/人间爱情指南-全书整合稿-v1.2.md#unit-D-1) 重大信息与行动 | 按用途核事实、意愿和方案，完整保留34项事项入口 | 不要求初识全填，不以未知推有罪，也不无限调查 |
| [E](../../../book/人间爱情指南-全书整合稿-v1.2.md#unit-E-1) 适婚与协商 | 综合价值、能力、运行与关键前提，区分判断、婚约和实施 | 其他优点不抵销决定性障碍，未落实不填已满足 |
| [F](../../../book/人间爱情指南-全书整合稿-v1.2.md#unit-F-1) 家庭财务 | 整理资金功能、流量、责任与可以计算的局部比率 | 不提供综合总分或统一婚恋资格线，未知与重大责任单独保留 |
| [G](../../../book/人间爱情指南-全书整合稿-v1.2.md#unit-G-1) 分工与公平 | 分配完整任务和权限，重看领域、整体及生命周期负担 | 不以每项对半作唯一标准，也不使不对称永久免于调整 |
| [H](../../../book/人间爱情指南-全书整合稿-v1.2.md#unit-H-1) 社会联系与亲属 | 看实际支持、影响、融入和共同生活边界 | 出资不授全部权限，名义支持不等于当前可用 |
| [I](../../../book/人间爱情指南-全书整合稿-v1.2.md#unit-I-1) 协商与修复 | 聚焦议题，确认权责，使用同一套七步并分层看结果 | 普通修复须有安全和自愿条件，不能平均侵害责任 |
| [J](../../../book/人间爱情指南-全书整合稿-v1.2.md#unit-J-1) 变化、照护与退出 | 准备关键功能，辨认责任来源、有限过渡与独立支持 | 能力有限不抹责任来源，善后未完不取消退出权 |
| [K](../../../book/人间爱情指南-全书整合稿-v1.2.md#unit-K-1) 身体与后果 | 确认当下具体同意、必要信息，以及一对一排他、拒绝与违约边界 | 不提供性行为教程或医疗处方，不以身份和经历取得身体权限 |
| [L](../../../book/人间爱情指南-全书整合稿-v1.2.md#unit-L-1) 概念与来源 | 查定义、整合方式、证据状态和使用范围 | 索引齐全不等于理论已经验证 |
| [M](../../../book/人间爱情指南-全书整合稿-v1.2.md#unit-M-1) 阶段与风险情境 | 使用90行完整表、传播案例、来源与判断更新页 | 不是危险预测量表；来源数不多计事件，未知不是低风险档 |
