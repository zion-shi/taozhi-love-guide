##### 空白决定卡

| 字段 | 填写 |
| --- | --- |
| 具体行动、目的与准备执行的范围 |  |
| 已知事实、来源与重要未知 |  |
| 双方各自愿意什么，哪些尚未同意 |  |
| 哪些由本人决定，哪些需共同同意，谁掌握第三方权限 |  |
| 真正可用的资源、附带条件及尚未落实来源 |  |
| 谁承担哪些事务、成本、风险和持续责任 |  |
| 不可逆或难撤回部分，最坏的现实后果能否承担 |  |
| 不做、晚做或采用其他路径的实际选择 |  |
| 若关系结束或条件变化，居住、财物和责任怎样处置 |  |
| 当前决定：不执行／暂缓／执行到什么范围 |  |
| 行动前仍需核实什么，什么变化会触发重看 |  |

身体决定由本人作出，不交给共同投票；共同资源与共同责任也不能由一方先行处置。涉及第三方资产、专业事实或具体法律安排，先确认权限与适用条件，不用一句“我们商量好了”替第三方作决定。
