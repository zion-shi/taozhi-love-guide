##### 清单二：长期关系优先项

写希望长期获得的生活，以及它为什么重要。若写“收入高”“有时间”等条件，再补一句它要支持什么安排，不由一个标签推断全部生活。

| 我长期重视什么 | 希望实现的具体生活及理由 | 哪些其他路径也可能实现，哪些条件待核 |
| --- | --- | --- |
|  |  |  |
|  |  |  |

虚构填写例：“我重视相对规律的共同相处，希望工作日也能有可以安排的见面，不只靠远期旅行维系。不同职业都可以了解，但要看实际地点和时间；收入优势不能替我接受长期没有共同生活的方案。”
