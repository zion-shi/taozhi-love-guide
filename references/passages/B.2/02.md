##### 清单一：不可妥协条件

只记目前真正影响本人是否进入或继续的事项，并把范围写清。个人可以坚持，但不能因此要求所有人作相同选择。

| 我目前明确不接受什么 | 对生活的影响及我的理由 | 什么情况下愿意重新理解或讨论 |
| --- | --- | --- |
|  |  |  |
|  |  |  |

虚构填写例：“我目前已明确不想生育，不接受以我将来一定改变为前提的婚姻安排。它关系到我的人生方向及现实承担。若我本人真实改变想法，可以重谈；不能仅因怕失去对方，就把仍未改变的意愿说成已经一致。”
