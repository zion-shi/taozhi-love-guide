##### 用自己的事实跟算：空白追踪页

先选一个月份、统一时点及资金范围，与[附录F.3的来源分类](../../../book/人间爱情指南-全书整合稿-v1.2.md#unit-F-3-heading-1)一致。先填来源小表，再按实际事件追踪去向；金额不明写未知，不用零代替。

| 来源类别 | 截至核对时点纳入的累计金额 | 依据、性质及原用途或义务 |
| --- | --- | --- |
| 本月实际可用收入 |  | 分列真实来源，不重复计入其他流入 |
| 纳入本次追踪的期初存量 |  | 来自哪项储备；原用途及余额怎样变化 |
| 新增借款 |  | 实际到账金额、来源及待履行义务；不算收入 |
| 其他真实来源及性质 |  | 说明性质和依据，不与以上项目重复 |
| 本次资金来源累计 |  | 未确认的部分单列；不声称已取得完整合计 |

来源发生变化时更新小表，事件表的来源累计回接同一时点的来源合计。内部转出、转入用同一个说明相连，只改变位置，不新增来源。

| 日期与事件 | 本次资金来源累计 | 本次资金仍在各处的合计 | 本次累计对外支付 | 其中已有用途或受限的部分 | 核对依据/未确认 |
| --- | --- | --- | --- | --- | --- |

|  |  |  |  |  |  |

同一资金范围、同一时点应满足：**本次资金来源累计＝本次累计对外支付＋本次资金仍持有合计**。已包含的受限或已有用途金额是仍持有资金的组成，不再相加；尚未纳入的期初储备不能拿来配平。动用存量要同步扣减原用途下的余额，借款增加资金也留下待履行义务，两者均不增加本月收入。前面的普通月示例只有20000元收入，没有新增借款或动用存量。

下月回看时，先用实际期末余额作新的期初，再看年内费用是否临近、必要支付是否改变、原授权和个人空间是否仍能用。长期目标的真实期初、未确认的重大义务，仍需要相应资料。算得平只说明已列项目对得上，不证明信息完整、分配公平或抗风险能力充足；这些分别接[附录F.2](../../../book/人间爱情指南-全书整合稿-v1.2.md#unit-F-2)、[G.3](../../../book/人间爱情指南-全书整合稿-v1.2.md#unit-G-3)及[F.4](../../../book/人间爱情指南-全书整合稿-v1.2.md#unit-F-4)、[F.5](../../../book/人间爱情指南-全书整合稿-v1.2.md#unit-F-5)、[F.6](../../../book/人间爱情指南-全书整合稿-v1.2.md#unit-F-6)。
